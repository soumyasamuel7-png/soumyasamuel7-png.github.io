## Overview

This file is a template. To add a new project to the site:

1. Duplicate this file inside `_projects/`.
2. Rename it to match your project, e.g. `_projects/my-new-project.md`.
3. Update the `title`, `date`, `excerpt`, and `tags` in the front matter.
4. Write the project details below the front matter.

It will automatically show up on the `/projects/` page, newest first, and get its own page at `/projects/my-new-project/`.
